# expense_tracker
Track your daily expenses easily with this beautiful web app.

## What can you do with this app?
- ✅ Add new expenses with date, amount, and category
- ✅ Edit or delete any exense from the interactive table
- ✅ See charts of your spending by category and over time
- ✅ Download your data as a CSV file
- ✅ Track your total spending and daily averages automatically
